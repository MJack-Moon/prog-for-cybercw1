# Security indecent manager

## Program description

This program acts as an indecent management menu, allowing the user to modify preset incident within the program.
The program allows the user to modify incident details, assign a status, update the risk level, remove information and display the remaining dictionary contents.

## Program description

### Incident information
- Username
- Ip address
- Event type
- Risk level

  
### incident status 

1. open
2. Under investigation
3. Resolved
4. Closed

### Risk level
1. Low
2. Medium
3. High
4. Critical

### Removing feilds
1. Removes username
2. Removes IP address
3. Removes event type
4. Removes risk level
5. Removes status
6. Exits

## How to run program 

1. Open a terminal in the repository.

2. Switch to the correct branch:
```bash
git switch security-incident-manager
```
3. Run the program:
```bash
python security_incident_manager.py
```
4. Follow the prompts to update the incident status and risk level.

5. Select a field to remove or exit.

6. Review the remaining incident information displayed by the program.
